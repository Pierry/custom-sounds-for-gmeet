Install on Chrome
downloadDownload extension (.zip)
  1. Download the .zip above and unzip it.
  2. Open chrome://extensions (paste it in the address bar).
  3. Turn on Developer mode (top-right toggle).
  4. Click Load unpacked and select the unzipped custom-sounds-for-gmeet folder.
  5. Open a Google Meet call. A panel appears in the corner. Click Configure sounds. For raise hand, click Learn and raise your hand once.

Bookmarklets are blocked by Meet's security policy, so this ships as an extension. This page is for previewing sounds. Works on Chrome and Chromium browsers (Edge, Brave).
